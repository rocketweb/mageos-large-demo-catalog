# OpenSearch Relevance Workbench source

`module-opensearch-relevance-workbench` is a clean Git archive of upstream
`rocketweb/module-opensearch-relevance-workbench` commit
`c11e95375c2a3e4f4550dd9c807fd059138e754b` from the `main` branch.

The archive is committed here so Composer installs only release source files.
Using the adjacent development checkout directly would also copy that checkout's
untracked `vendor/` directory and load duplicate dependencies in Magento.
